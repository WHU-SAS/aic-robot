# AIC Robot｜视觉追踪与自主抓取机器人

基于 **K230 与 MSPM0** 的移动抓取机器人，面向 **20 mm 蓝色方块**，完成视觉追踪、底盘接近、停车定位和机械臂抓取，并在夹取失败或目标丢失后恢复任务。

当前主线由 K230 运行视觉、语音与任务逻辑，MSPM0 执行底盘控制；整车任务在板端运行，电脑用于开发、部署与调试。

## 系统组成

| 组成 | 职责 |
| --- | --- |
| **K230** | 语音触发、视觉定位与目标追踪、整车任务调度及机械臂指令 |
| **MSPM0** | 车轮速度、直行与转向控制，以及编码器反馈 |
| **六轴机械臂** | 停车后执行定位抓取与抬升 |

K230 通过 UART 与 MSPM0 通信，并通过 URT-2 连接机械臂舵机。硬件型号、供电和接线见 [硬件说明](docs/hardware/connections.md)。

## 当前进展

| 范围 | 状态 |
| --- | --- |
| **已演示** | 自主追踪抓取、夹取失败重试、目标丢失后的重搜与追踪，见上方视频 |
| **仍在验证** | 重复运行稳定性、任务成功率、定位与抓取精度，以及不同场景下的表现 |
| **尚未实现** | 指定位置放置、独立视觉持物验证 |

当前夹住判断依据夹爪舵机反馈，不等同于独立视觉确认；相机标定的拟合误差也不直接代表实物抓取精度。当前版本、测试条件和验证边界见 [全流程追踪说明](docs/guides/full-process-tracking.md)。
