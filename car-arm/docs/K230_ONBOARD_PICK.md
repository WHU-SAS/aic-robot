# K230板端识别与抓取流程

## 入口

```bash
./scripts/host hardware/k230_blue_pick_onboard.py --execute --hands-free
```

IDE需停止并断开。每轮重新识别，不要求先回中立；从实际编码规划。只识别使用`--detect-only`，显式同帧局部图诊断使用`--detect-only --debug-roi`。首次设置串口权限见[README](../README.md)。

## 识别与坐标

K230使用1280×960 RGB565，实际画面不镜像、不翻转。预热30帧，最多采9帧；LAB寻找候选，HSV分离蓝色连通区，测量外轮廓和内部棱线。粗糙边缘采用原轮廓及合并到六边后的候选；保留独立物理面候选。

正常将坐标、边界质量和计时传给PC；图像处理在K230。PC先匹配三个不同帧的轮廓或同来源同物理面角点，跨度≤5px，再计算20mm方块位姿：

- 优先完整三维立方体六外棱解算；至少一条内部棱线证据、六条外棱支持≥6且直线RMS≤3px。
- 立方体边线法向拟合RMS≤2px、最大≤4px，正深度，全部8顶点投影包含检查。
- 独立物理面按原平面PnP重投影≤2px、面法向与顶侧中心一致性≤8mm筛选。
- 缺乏独立验证的旧侧面候选不单独采用。角点外推误差和边线法向拟合误差分别记录。

内外参使用`k230/calibration/runtime/`冻结快照；从相机中心坐标变换到Base坐标。定位失败发生在打开舵机串口前。

## 水平目标与逆解

原始中心通过`CUBE_CENTER_Base_mm`打印。抓取XY沿Base原点指向方块外移10mm：

`目标XY = 视觉XY × (1 + 10 / 视觉XY距离)`（各量以mm计）。

补偿目标通过`GRASP_TARGET_Base_XY_mm`打印，并在`execution.json/target_compensation`保留原始/补偿坐标。每轮只应用一次。目标高度采用估计桌面及配置，不直接拿视觉Z作为指尖高度。

名义对齐参考为预计夹住20mm方块时两指末端中点，旧固定爪偏移已去除。先读取六轴编码、只读核对参数，再求四阶段IK；腕部倾角优先25°，在既定20～45°候选内寻找完整方案。当前位置开扭矩时先锁定当前位置。`--hands-free`跳过终端放手确认。

## 四阶段动作

| 阶段 | 目标 | 发送后推进方式 |
| --- | --- | --- |
| hover | 张开30°/2389，与上方姿态一次同步发送；模型最低指尖80mm | 采样观察6秒 |
| descend | 保持开口，到模型最低指尖15mm | 采样观察6秒 |
| close | 保持其他轴目标，6号到预计接触目标再闭合20计数 | 连续0.5秒位置范围≤2计数；复读仍满足后推进 |
| lift | 保持闭合，移动到规划80mm抬升姿态 | 采样观察8秒 |

每阶段只有一次六轴最终目标同步包，后续只采样，不循环写小步目标。6秒/8秒是观察窗口，速度由当前运动配置决定；闭合等待没有固定3秒超时。同步关节目标的实际末端路径由各舵机速度/加速度与机构决定。

1/5/6速度/加速度150/5，2/3/4为600/20。参数源：`hardware/user_selected_pid_demo_baseline.json`和`hardware/motion_defaults.json`。程序只核对PID，不永久写参数。

## 完成、记录与失败

流程完成保持抬升姿态和扭矩。实际抓起由现场确认，尚未增加放置或抓取成功自动判断。

每轮独立保存`hardware/logs/k230_pick_时间戳/`：角点、计时、定位结果、目标、逐阶段反馈、最终偏差和基于实际编码的理论FK坐标。反馈FK和高度仍是模型值。

板端将最后识别帧的局部JPEG缓存到SD；正常成功只传坐标，定位失败时主机尝试按偏移/长度/SHA256取回同帧`frame_roi.jpg`，不重新拍摄。显式诊断直接传所需图像；存图失败不影响有效坐标。手动中断不触发额外取图。

动作中报错会停止后续目标发送，程序不自动回中立或断扭矩。保持原基础参数核对、通信有效性和关节范围检查；没有重新加入历史PID试验的动态误差/速度峰值保护。

## 验证与适用范围

2026-10-13用户现场接受当前版本。此前进行了保存图片/角点回放、六棱拟合、失败图传输模拟和四阶段IK验证。新电脑可运行`./scripts/host scripts/offline_check.py`及`./scripts/host -m unittest discover -s hardware/tests`；历史原图回放另外需要本地数据。

该结果适用于当前相机焦点/模式、相机与底座相对位置、桌面及20mm蓝色方块；没有据此声明新的实测毫米误差。
