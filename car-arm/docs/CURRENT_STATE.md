# 当前状态（2026-10-13）

## 已接受的版本

用户已现场运行并接受：K230定位蓝色20mm方块 → 逆解 → 张开悬停 → 下探夹取 → 抬升。团队仓库模块目录为car-arm，原独立项目目录为AIC car-arm，代码和模型独立于USB摄像头项目。

- 默认入口：`hardware/k230_blue_pick_onboard.py`。
- 当前抓取设置：30°张开/2389、下探模型15mm、悬停/抬升规划80mm、XY径向伸展10mm、额外闭合20计数、6号静止0.5秒后抬升。
- 每阶段一次同步发送六轴最终目标；1/5/6速度150、加速度5；2/3/4速度600、加速度20。
- PID/积分限幅由用户确定，配置为准；抓取程序只读核对，不自行调参。
- 正常流程结束保持扭矩和抬升姿态；未加入放置、自动回中立或断扭矩。
- 抓起确认目前依赖现场观察，夹爪静止仅用于决定抬升时机。

## 实际使用的标定

`hardware/k230_pick_config.json`引用：

- `k230/calibration/runtime/camera_intrinsics.json`：当前对焦、1280×960内参。
- `k230/calibration/runtime/camera_in_base.json`：同批动作1配对样本拟合的相机到底座外参。
- 两文件由原运行文件逐字节复制，SHA256及内外参配套关系已核对；迁移不改变数值。
- 桌面Base Z约−63.305mm。历史候选、实验照片和误差报告留在本地实验目录。

用户接受的是此版本的现场表现；内外参和机构参考仍是经验标定，不由现场评价推导新的毫米精度指标。历史同焦点留出验证XY RMS约8.4mm、XYZ约10.0mm属于对应点拟合诊断。
