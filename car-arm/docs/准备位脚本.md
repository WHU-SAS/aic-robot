# 准备位脚本

用户指定角度（ID 1～6）：`0°、−80°、+80°、+80°、0°、+30°`。6号为舵机相对闭合零位的张开方向角度，不是实测两指开口夹角。当前映射对应编码：`2048、1138、2958、2958、2048、2389`。

配置见 `hardware/ready_pose.json`；入口为 `hardware/move_ready.py`，复用现有任务控制器，不改PID、速度/加速度或控制策略。

## 离线预览

```bash
cd car-arm
./scripts/host hardware/move_ready.py
```

不访问硬件；默认假定从六轴2048出发。其他起点可指定 `--start-counts` 后跟六个编码。

## 现场执行

```bash
cd car-arm
./scripts/host hardware/move_ready.py --execute
```

输入命令即授权本次准备位动作，无需再输入“已放手”或“确认”。程序只读核对当前参数、模式与编码限位；需要上扭矩时先初始化当前位置保持，随后一次同步发送六轴准备位目标并退出，扭矩保留。目标发送不声称已经到位；请现场观察。

若先前旧进程还在等待输入，先按Ctrl+C结束旧进程，再执行上述命令，释放串口占用。

本次“立即执行”仅适用于准备位入口；其他任务的人工确认方式保持原样。

1、5、6号速度/加速度为150/5；2、3、4号为600/20，均从当前配置加载。此单阶段任务不会追加回中立或断扭矩动作。确认目标已发送不代表已经停稳；到位情况由现场观察确认。

用户首轮执行在旧模型间隙预检阶段被拒绝，未发送移动目标。日志起点的指尖模型Base Z约14～16mm，低于旧30mm门槛。2026-10-13用户明确同意仅准备位取消该检查；当前脚本自动选择此例外，日志明确记为未做模型几何检查，不声称路径已认证。此例外只接受本页指定的单个准备位目标且必须保持最终位；不影响其他任务的模型检查，不更改全局控制策略。

用户随后明确要求命令后立即执行：准备位入口已取消全部终端输入等待，命令调用本身作为本次目标发送授权。参数/限位/通信检查保留。修改后只做离线预览与模拟控制回归，没有执行新的真机动作。
