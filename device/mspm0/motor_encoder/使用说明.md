# Demo 01：按键控制双电机与编码器计数

适用：立创天猛星 MSPM0G3507、现有 TB6612 双路稳压驱动板、两台 MG513XP28_12V 电机。

## 这次学什么

1. GPIO 决定电机方向。
2. PWM 占空比决定驱动强度。本例 10 kHz、最大 20%，不是恒定转速控制。
3. 编码器两相信号产生中断，程序累计计数。
4. 按键切换运行状态，定时器每 10 ms 执行控制。

上电默认停止。松开 B21 后按下，约 0.5 秒内逐渐增加到 20% 占空比；再次按下 B21 停车。每次最长运行 5 秒，超时后需要重新按键。按键持续按住不会反复启停，上电时按住也不会启动。

停车通过 STBY 拉低关闭驱动，车轮可能因惯性继续转动片刻。本程序用于车轮悬空的桌面实验。

## 1. 接线

先断开电池。第一版由电脑 USB 给天猛星供电，电池给绿色驱动板供电，两板 GND 相连。**绿色板的 5V/3.3V 输出不要再接到已经 USB 供电的天猛星电源脚。** 电池只接驱动板的电源输入。

按 PCB 丝印找引脚，不按插头朝向或线色猜测。A/B 表示驱动板通道，不预设哪个是左轮。

| 绿色 TB6612 板信号 | 天猛星引脚 | 功能 |
|---|---|---|
| GND | GND | 共同参考地 |
| PWMA | PB2 | 电机 A PWM |
| PWMB | PB3 | 电机 B PWM |
| AIN1 | PA14 | 电机 A 方向 |
| AIN2 | PA13 | 电机 A 方向 |
| BIN1 | PA16 | 电机 B 方向 |
| BIN2 | PA17 | 电机 B 方向 |
| STBY | PA12 | 运行使能，低电平停车 |
| E1A | PA25 | A 通道编码器相位 A |
| E1B | PA26 | A 通道编码器相位 B |
| E2A | PB20 | B 通道编码器相位 A |
| E2B | PB24 | B 通道编码器相位 B |

**STBY 本例改接 PA12，不沿用厂家图中常接 3.3V/5V 的方式，也不要同时接电源。** 两个电机继续使用现有配套六芯线连接绿色板的电机插座，包含电机驱动、电源与编码器信号。

照片上的绿色板电机口标有 3V3。首次接编码器信号前，确认本块板 E1/E2 输出高电平不超过 3.3V；若测到 5V，应先处理电平转换，不能照着通用旧教程的“5V 直接接 IO”接线。电机口的 AO/BO 是功率输出，不能接 MCU。

首次仅接上述模块，巡线板、IMU 暂不接入。B21 是天猛星自带用户键，无需外接；BSL 用于下载，RST 用于复位。

## 2. 固件与编译

- 已生成固件：`build/motor_demo.hex`。
- 带调试信息的文件：`build/motor_demo.axf`。
- Keil 工程：`keil/motor_demo.uvprojx`。
- 程序入口：`main.c`；启停逻辑：`demo_control.c`；可调参数：`demo_control.h`。

命令行复现编译（在此目录运行）：

```powershell
python build.py --toolchain D:/Keil_v5/ARM/ARMCLANG/bin
```

使用已有 Arm Compiler 6.16 和厂家包内 DriverLib，无需安装整个 CCS 来编译此版本。脚本只编译，不烧录。Keil GUI 工程选用本机已有 Arm Compiler 6；调试器连接与器件包配置仍需按实际安装情况设置。

Keil 工程关闭了自动运行 SysConfig 的构建钩子，以已检查的 `ti_msp_dl_config.c/.h` 为编译依据。`reference/empty.syscfg` 已记录本例引脚调整，但尚未通过 SysConfig 工具重新生成验证；后续若重新生成，必须复核按键上拉、STBY、定时器启动状态和 UART 关闭回环。原厂家 empty.c、Hardware、重复驱动及旧工具已隔离归档到仓库 `third_party/reference/motor_template/`，不参与构建。

## 3. 第一次下载：先只接主控 USB

先断开电池和驱动板信号线，用 USB 数据线连接天猛星。

可使用立创官方 [MSPM0 在线烧录工具](https://wiki.lckfb.com/storage/html/mspm0-web-flasher/index.html)：

1. 用 Edge 或 Chrome 打开工具。
2. 按住 BSL，按一下 RST，先松 RST，再松 BSL，进入下载模式。
3. 连接开发板对应 COM 口，选择本目录的 `build/motor_demo.hex`，按工具步骤烧录。这会替换原应用程序。
4. 下载完成后释放所有按键并复位，断开网页的串口连接。
5. 用串口终端打开同一 COM 口，设为 **115200、8 数据位、无校验、1 停止位、无流控**。

天猛星 Type-C 带串口功能，所以首轮可以直接通过 USB 查看日志，无需额外购买 USB-TTL。BSL 下载时的波特率按烧录工具设置；应用日志是 115200，两者不要混淆。

### 改用野火 fireDAP 下载和调试

2026-09-29：用户反馈原 J-Link 无法使用，现已更换为照片中的野火 fireDAP。后续按 CMSIS-DAP/SWD 路径配置。调试器变化不需要修改 Demo 控制代码或重新生成固件；连接与实际下载尚未验证。

断开电池与电机驱动板信号线，按 fireDAP 外壳 **SWD** 一栏的信号名称接线。当前照片没有露出实际插针，因此下表只给信号对应关系，不按照片方向猜插针位置。

| fireDAP SWD 信号 | 天猛星对应信号 |
|---|---|
| VREF | 3V3（目标板参考电压） |
| TMS | SWDIO / DIO / PA19 |
| TCK | SWCLK / CLK / PA20 |
| GND | GND |
| RST | NRST / RST（复位网络，不是 BSL 或 B21） |

天猛星由自己的 Type-C 接电脑供电，fireDAP 的 USB 也接电脑。VREF 用于感知目标板电平，不能作为给主控供电的输出。四针调试口若没有 RST，可从开发板已确认的 NRST 引出点连接；不要猜针脚。不要拿 V-UART 一组当作 SWD 接口。

Keil 操作：

1. 打开 `keil/motor_demo.uvprojx`，进入 `Options for Target → Debug`。
2. 选择 **CMSIS-DAP Debugger**，点击 **Settings**，在 Adapter 列表选择实际识别到的 fireDAP。
3. Port 选择 **SW**，初次将调试时钟设为 **100 kHz**。已接 RST 时，连接困难可尝试 `Connect: under Reset`；未接 RST 时不要依赖此方式。
4. 先确认 SW Device 能读到目标芯片的调试 ID，再进行下载。不要按 STM32 示例的 ID 数值判断这块 MSPM0。
5. 在 Flash Download 页确认使用 **MSPM0G3507 对应的 Main Flash 128KB 算法**，而不是 STM32 算法；Utilities 使用同一调试器。若器件或算法缺失，先配置厂家提供的 MSPM0 器件包。
6. 编译并执行 Download，完成后复位运行。通过主控 Type-C 串口观察 115200 波特率日志。使用 fireDAP/SWD 时通常无需按 BSL 进入串口下载模式。

如果电脑未识别 fireDAP，先排查 USB 数据线和 USB 口；野火文档说明 DAP 调试功能一般无需单独驱动，VCOM 串口驱动是另一项功能。本 Demo 继续使用天猛星自身串口，fireDAP 的 V-UART 暂不接。

依据：[野火 DAP 官方说明（CMSIS-DAP、VREF 与驱动）](https://doc.embedfire.com/stm32_products/must_read/zh/latest/doc/quickstart/DAP/DAP.html)。该页部分截图针对 STM32，只参考调试器操作，目标器件和 Flash 算法必须选择 MSPM0G3507。

## 4. 分三步验收

### A. 只检查主控

USB 供电，不接电机驱动。串口应每 100 ms 出现一行。`run` 初始为 0、`pwm` 为 0。按 B21 后 run=1、pwm 逐步升到 1600，再按一次或等待 5 秒应归零。

### B. 检查编码器

断电后接好地线、编码器线和控制线，抬高底盘，确保两只驱动轮离开桌面。接电池并打开绿色板开关，保持 run=0。

轻轻转动一个车轮，查看对应 `a_total` 或 `b_total` 是否变化；反向转动，变化方向应相反。另一通道应基本不动。若不符合，先查 E1/E2 接线，暂不启动电机。

### C. 检查电机

保持车轮悬空，按 B21。两轮应逐渐转动，再按 B21 应停止驱动，未按键则 5 秒后自动停止。首次确认开关在手边；运行中不要按调试器暂停，因为暂停 CPU 可能让硬件 PWM 继续输出，软件超时也会停止计时。

20% 占空比可能不足以克服某些电机的静摩擦。如果不转，先停车检查电源和接线，不要让电机堵转。需要改变驱动量时，修改 `DEMO_PWM_TARGET` 并重新编译，PWM 周期为 8000。

若两轮使车身运动的方向相反，停车后修改 `main.c` 的 `MOTOR_A_REVERSE` 或 `MOTOR_B_REVERSE`，重新编译。第一版原始编码器正负号未做左右轮方向归一化，两个计数符号相反不一定是接错。

## 5. 串口数据怎么看

```text
ms,run,pwm,a_100ms,b_100ms,a_total,b_total,stop_reason
```

- `ms`：启动后的毫秒数。
- `run`：0 停止、1 运行。
- `pwm`：0～1600；1600/8000=20%。
- `a_100ms/b_100ms`：各通道最近 100 ms 的有符号计数。
- `a_total/b_total`：从开机起累计计数，停车不清零；按 RST 清零。
- `stop_reason`：0 上电或当前运行，1 按键停车，2 超时停车。

输出的是原始计数，不是 RPM。厂家闭环例程默认“13 线、2 倍频、30:1”，你们电机的实际参数还未确认，故未套用。当前两相都只采上升沿，属于 2 倍频；同时积压两相中断时丢弃歧义样本，适合低速入门，不保证高速无丢计数。
