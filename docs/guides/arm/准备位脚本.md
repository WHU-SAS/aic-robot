# 回准备位：小车行驶时的平衡姿态

## 用途与必须保持的状态

用户明确要求：**小车行驶过程中，机械臂始终保持此准备位，用于维持整车平衡。**

- 小车开动前执行回准备位，确认机械臂到位并停稳。
- 行驶期间保留扭矩，保持准备位；改变机械臂姿态的抓取等操作在小车停稳后执行。
- 当前没有与小车启动自动联动，也没有到位信号自动确认；后续小车任务入口应按此约定衔接，具体控制设计由用户决定。

## 执行命令

在本模块根目录执行：

```bash
./scripts/arm-ready --execute
```

在团队仓库根目录 `/home/xd/Desktop/aic-robot` 执行；旧独立项目不再用于开发或运行。

输入命令即授权本次动作，不需要额外终端确认。程序读取当前编码、核对已保存参数及关节限位；需要开扭矩时先初始化当前位置保持，再一次同步发送准备位六轴最终目标。发送后脚本退出，六轴保留扭矩，不追加回中立或断扭矩。命令完成表示目标已发送，到位、停稳由现场确认。

## 准备位目标

| 舵机 | 目标角度 | 目标编码 |
| --- | --- | --- |
| 1 | 0° | 2048 |
| 2 | −80° | 1138 |
| 3 | +80° | 2958 |
| 4 | +80° | 2958 |
| 5 | 0° | 2048 |
| 6 | +30° | 2389 |

6号角度是相对闭合零位的舵机输出角，计数量化后约29.97°。准备位与六轴2048中立位不同。

**这个目标包括张开夹爪。** 当前脚本不检测是否持物；持物行驶时如何保留夹持、如何放置等策略需另行由用户确定。本次文档更新没有更改6号或其他轴目标。

## 现有运行设置

配置为`configs/arm/ready_pose.json`；通过`host/apps/run_task.py`与任务控制器发送。1/5/6速度/加速度150/5，2/3/4为600/20，沿用已保存PID与运动配置。只读核对PID，不写参数。

此准备位按用户既有授权省略继承的模型桌面路径门槛；编码/设备限位、参数核对、通信有效性检查保留。这个现有例外只适用于指定准备位，未扩大到其他任务。

## 离线预览

```bash
./scripts/arm-ready
```

不访问硬件；默认从六轴2048计算。可用`--start-counts`后跟六个编码指定离线起点，实际执行读取现场编码。
