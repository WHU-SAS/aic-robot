# 行驶准备位

**小车行驶时，机械臂保持此姿态和扭矩，以维持平衡；停车后再抓取。**

```bash
./scripts/arm-ready --execute
```

程序读取实际编码、核对参数与关节限位，需要开扭矩时先锁定当前位置，再一次同步发送六轴目标并退出。**退出只表示目标已发送，到位和停稳由现场确认。** 当前未与小车启动联动。

| 舵机 | 角度 | 编码 |
| --- | --- | --- |
| 1 | 0° | 2048 |
| 2 | −80° | 1138 |
| 3 | +80° | 2958 |
| 4 | +80° | 2958 |
| 5 | 0° | 2048 |
| 6 | +30° | 2389 |

准备位不是六轴 2048 的中立位。**夹爪会张开**，脚本不检测持物；持物行驶策略待用户确定。

配置为 `configs/arm/ready_pose.json`，沿用 [舵机基线](BASELINE.md)，不写 PID。用户授权的模型桌面路径门槛例外只用于本准备位。

离线预览运行 `./scripts/arm-ready`，不访问硬件；默认起点为六轴 2048，可用 `--start-counts` 后跟六个编码覆盖。
