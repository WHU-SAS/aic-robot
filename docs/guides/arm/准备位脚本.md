# 行驶准备位

**小车行驶时，机械臂保持此姿态和扭矩，以维持平衡；停车后再抓取。**

```bash
./scripts/arm-ready --execute
```

程序读取实际编码、核对参数与关节限位，需要开扭矩时先锁定当前位置，再一次同步发送六轴目标并退出。**退出只表示目标已发送，到位和停稳由现场确认。** 当前未与小车启动联动。

| 舵机 | 角度 | 编码 |
| --- | --- | --- |
| 1 | 0° | 2048 |
| 2 | −80° | 1138 |
| 3 | +80° | 2958 |
| 4 | +80° | 2958 |
| 5 | 0° | 2048 |
| 6 | +25° | 2332 |

准备位不是六轴 2048 的中立位。**夹爪会张开**，脚本不检测持物；持物行驶策略待用户确定。

配置为 `configs/arm/ready_pose.json`，沿用 [舵机基线](BASELINE.md)，不写 PID。用户授权的模型桌面路径门槛例外只用于本准备位。

离线预览运行 `./scripts/arm-ready`，不访问硬件；默认起点为六轴 2048，可用 `--start-counts` 后跟六个编码覆盖。

## 通过K230发送

URT-2未接PC USB而接K230 UART1时，可用现有IO3→TX、IO4←RX、GND与5V逻辑供电接线，电平档3V3、舵机独立供电。无需把URT-2改接PC；CanMV IDE须停止并断开。参数仍从本仓库同一准备位、关节映射、PID基线及速度配置读取。

```bash
./scripts/host tools/diagnostics/k230_arm_ready.py                        # 只读检查
./scripts/host tools/diagnostics/k230_arm_ready.py --execute --hands-free  # 手离开后执行，按需开扭矩
# 可选：只锁住当前位置，不回准备位
./scripts/host tools/diagnostics/k230_arm_ready.py --execute --hold-current
```

第一条不写任何寄存器。第二条按需开启未上扭矩的轴，再一次同步发送准备位最终目标，报文发完立即退出，不再读取反馈或持续监控；到位和停稳由现场观察，扭矩保留。第三条仅锁住当前位置。目标及各轴速度/加速度的报文字节已与原STS SDK核对。本入口不自动启动底盘；到位由现场确认后再做地面测试。

仅写SRAM的目标/速度/加速度与扭矩开启；不写PID、EEPROM、限位或扭矩关闭，失败也不发额外恢复动作。原始记录留在本机 `data/logs/k230_arm_ready_*/`。2026-10-20已完成K230六轴参数双读、当前位置锁定、一次同步准备位实测；用户确认平稳后执行底盘约1秒短前进，反馈无异常。停车后复读六轴目标未变、扭矩均为1、速度为0。

也可用独立或完整包语音指令“回准备位”，目标与本页相同，包括夹爪张开。语音入口只读六轴扭矩；若有未开启轴，只给这些轴写入当前位置目标，再开启并核对扭矩，最后同步准备位目标。已开启轴不重复开启；最终目标发送后不读回、不监控。先按[录音与部署步骤](K230_STANDALONE_PICK.md#注册回准备位)注册，完成后直接说该指令；无需先唤醒抓取。
