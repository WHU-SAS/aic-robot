# 三组固定动作 PID 对照

在仓库根目录运行，K230 OTG 接电脑、IDE停止并断开；舵机上电且扭矩已开启。清空下降位置，模拟时使用空夹爪。

```bash
./scripts/pid-three --execute --label baseline
```

顺序为准备位→近处→准备位→中距→准备位→远处→准备位。每段一次同步发送六轴最终目标，使用当前舵机PID及项目速度/加速度；夹爪全程30°张开。三组目标来自已执行的下降日志，固定在 `configs/arm/pid_three_actions.json`，模型最低指尖高度约15mm。运行时直接读目标表。

默认动作采样5秒、准备位3.5秒，一轮窗口共29秒；实际会多出连接和最后一轮串口读取的时间。每段按时进入下一段，指标只用于记录。需要更长对照时可加 `--action-seconds 6`。不加 `--execute` 只显示目标表。

原始六轴反馈及每轴采样时间、实际PID、完整目标和结果保存在 `data/logs/pid_three_*/`。`summary.txt` 可直接阅读；`summary.json` 用于对比。采样间隔以日志实测为准，50ms只是最快轮询周期，不足以承诺捕捉高频振动。

| 指标 | 定义 |
| --- | --- |
| 最终偏差 | 最后编码−目标编码，正号为编码正方向偏差 |
| 停稳秒 | 从发送目标到进入末尾0.5秒中位值±2计数，并在余下窗口保持至少0.5秒 |
| 修正秒 | 首次接近最终值±12计数，到上述停稳的时间；不包含大跨度行程 |
| 目标带秒 | 从发目标到进入目标±6计数并保持到窗口末尾至少0.5秒 |
| 尾段波动 | 最后一秒最大编码−最小编码 |
| 折返次数 | 接近最终值后，至少3计数的方向反转次数；可能包含过冲后的正常一次回调 |

`--`表示窗口内未确认，不额外等待。缺失反馈时不报告停稳或修正时间。有限采样只能判断已记录的编码变化，不能排除采样间隙内的抖动。

开始测试会暂停语音监听，结束保持准备位及当前扭矩，可直接重跑；重启K230后恢复原独立语音程序。Ctrl+C停止后续目标发送，已发目标和扭矩保持。脚本只写动作目标/速度/加速度；PID、扭矩和EEPROM沿用当前值。
