# 新外参：PC全流程抓取验证

在仓库根目录运行；K230和舵机接通，CanMV IDE停止并断开。沿用当前K230 UART1到URT-2的机械臂接线，无需连接URT-2的电脑USB。

```bash
cd /home/xd/Desktop/aic-robot
./scripts/pick-pc --execute --hands-free
```

每次重新拍照和规划，可移动方块后重复同一命令。`--hands-free`表示执行时已经放手；省略它，则先锁定当前位置，再等待输入“已放手”。

## 执行顺序

1. K230拍摄1280×960原图并校验回传；PC使用OpenCV识别20mm蓝色方块，以2026-10-22新外参转换到机械臂Base坐标。
2. 读取六轴位置、核对保存的参数和限位，计算完整四阶段IK；识别或规划失败时不发送移动及扭矩指令。
3. 未开启扭矩时先设置当前位置目标，再开启保持；不写PID或EEPROM。
4. 同步到方块上方并张开30°；同步下探；闭合；夹爪编码连续0.5秒处于±1计数静止带后同步抬升。板端每次只执行一个阶段，PC收到完成结果才发送下一段。
5. 结束保留抬升姿态和扭矩，由人观察是否实际夹起；不自动放置、回位或卸力。

| 项目 | 本次值 |
| --- | --- |
| 夹爪张开 | 30°，2389计数 |
| 悬停 / 下探 / 抬升 | 最低指尖模型高度80 / 15 / 80mm |
| 额外夹紧 | 20计数 |
| 额外向前伸展 | **0mm**，不沿用第0版的10mm补偿 |
| 1、5、6号速度 / 加速度 | 150 / 5 |
| 2、3、4号速度 / 加速度 | 600 / 20 |
| 悬停 / 下探 / 抬升观察时间 | 6 / 6 / 8秒；闭合单独等待静止 |

桌面Base-Z高度按新标定平面在目标XY处计算，未沿用旧桌面常量。高度和夹持中心仍是模型预测，实物误差由本轮验证。静止判定只说明夹爪停止，不代表已夹住方块。

Ctrl+C会停止当前采样脚本和后续阶段，已经发送的舵机目标仍可能继续执行；保持扭矩，不发送反向恢复动作。

## 单独定位、规划与人工偏移

```bash
./scripts/pick-pc --detect-only   # 新拍照、定位，不访问舵机
./scripts/pick-pc                 # 新拍照、读编码、规划，不开扭矩或移动
./scripts/pick-pc --image /绝对路径/frame.jpg # 离线图像回放，不连接硬件
```

确认固定偏差后可自行指定Base坐标偏移，单位mm；默认三项均为0。例如将目标沿Base-X增加3mm：

```bash
./scripts/pick-pc --execute --hands-free --offset-x-mm 3
```

另有`--offset-y-mm`和`--offset-z-mm`；Z偏移作用于三个模型指尖高度。偏移只作用于本次规划，不修改原始视觉坐标、外参或PID，不自动学习补偿。

## 配置和日志

- 动作：`configs/arm/pick_validation_pc.json`。
- 视觉和桌面平面：`configs/vision/trials/fixed_tip_top_20261022.json`；外参位于同目录配对文件，与内参哈希核对。
- PID和速度：继续读取`configs/arm/user_selected_pid_demo_baseline.json`及`motion_defaults.json`。
- 每轮日志：`data/logs/pick_pc_时间/`，包含原图、识别标注、视觉解、四阶段目标与FK、六轴反馈、最终偏差和耗时。

新入口已通过离线回放、阶段逻辑与中断测试，真机全流程待本轮验证。正式外参候选仅供本入口使用，不替换第0版演示配置。
