# K230独立语音抓取

K230本机完成语音、拍照、定位、FK/IK及舵机控制，运行不需要PC。抓取结束保持抬升与当前扭矩；尚未接入指定位置放置或整车任务调度。

## 使用

1. 保持现有接线和舵机供电，在桌面识别区域放好20mm蓝色方块。
2. K230启动后仅监听，看到状态监视中的“监听就绪”后使用。首次启动包含约5.12秒音频预热，总初始化时间更长。
3. 说“思达思达”触发一次抓取；直接说“回准备位”调用[准备位](准备位脚本.md)，夹爪会张开30°。

当前动作以`9b7e306`为基础，5号保持本轮读到的角度，暂停自动旋转。试验版本保留于Git标签`archive/wrist-rotation-trial-20261023`，不是当前功能。

## 抓取阶段

参数来源：`configs/arm/pick_validation_pc.json`、[PID与速度基线](BASELINE.md)。

| 项目 | 当前值 |
| --- | --- |
| 对齐参考 | 张开30°时两指末端中点，方块向固定爪侧偏45mm |
| 额外径向前伸 | 0mm |
| 最低指尖模型高度 | 悬停80 / 下探15 / 抬升80mm |
| 额外夹紧 | 20计数 |
| 1/5/6号速度、加速度 | 150 / 5 |
| 2/3/4号速度、加速度 | 600 / 20 |

1. 规划完成后一次同步发送悬停最终目标；一轮六轴读数均在目标±30计数后下探。
2. 下探先发4号最终目标，200ms后同步发送其他五轴最终目标。
3. 一轮六轴均在下探目标±10计数后闭合。该轮读数复用为`descend_position_sample`，记录实际−目标偏差及读取耗时。
4. 只读6号，连续5次位置在同一±1计数带内（最大−最小≤2）后抬升。逐次挪动1计数不能累计成静止。
5. 一次同步发送抬升目标，固定等1秒后重新建立语音监听，不重复首次音频预热。

轮询间隔50ms，实际周期包含串口读取；六轴顺序采样。未满足阶段条件继续等待，读取失败不推进。1秒等待、编码静止或流程完成都不证明已到位或抓起。

此入口沿用当前扭矩，不开扭矩、不写PID。失败或停止脚本后不自动归位、卸力；已发目标仍可能执行。运动期间不监听或排队语音。“回准备位”只同步发送最终目标，不前检、不读回、不等到位，保持当前扭矩状态。

## 状态监视

先停止并断开IDE，执行：

```bash
./scripts/k230-status
# 可选：--raw --seconds 30 --port /dev/serial/by-id/设备名
```

监视器只接收，不发字节或中断板端程序；Ctrl+C仅退出PC监视。显示监听就绪、每5秒实际采样/推理心跳、定位坐标、阶段及失败原因。晚连接可能缺少此前日志；IDE或USBDBG会中断启动程序，退出调试后仅重启K230恢复监听，保留舵机供电。

## 部署

在仓库根目录、IDE停止并断开时执行：

```bash
./scripts/deploy-pick                     # 仅生成本地包
./scripts/deploy-pick --install           # 写入、回读校验，不切换版本
./scripts/deploy-pick --install --activate # 设置下次启动版本
```

部署不重启K230、不发动作。完成后仅重启K230，确认两项语音指令及持续监听状态。每次部署保留旧release、启动文件和指针备份，记录在本机`data/deployments/`。

### 注册回准备位

“回准备位”已注册；需重录时先退出状态监视，运行`./scripts/enroll-ready`，按终端提示录三遍。`./scripts/enroll-ready --listen --seconds 30`仅测试识别，不运动；录完重新部署。录音文件在SD卡`/sdcard/voice/`，不覆盖原唤醒词。

## 文件与诊断

| 文件 | 职责 |
| --- | --- |
| `device/k230/pick/app.py`、`voice_commands.py` | 语音分发、媒体切换、单次抓取与日志 |
| `device/k230/vision/runtime.py`、`camera.py` | [共用结果和相机独占](../vision.md#共用结果与相机) |
| `device/k230/pick/vision.py`及同目录选面文件 | 物理面识别、位姿与桌面筛选 |
| `device/k230/pick/kinematics.py` | 与当前模型一致的FK/IK |
| `device/k230/arm/pick_stage.py`、`ready_pose.py` | 抓取阶段和直接准备位命令 |
| `tools/deploy/k230_pick.py` | 打包代码、配置及模型，SD回读校验 |

SD上的运行数据：

- `/sdcard/main.py`、`/sdcard/aic/pick/current.json`：启动入口与release指针。
- `/sdcard/aic/pick/releases/<哈希>/`：代码、模型、配置及manifest。
- `/sdcard/aic/pick/events.jsonl`、`last_frame.jpg`：最近运行事件与原图。

内外参、选面规则与未解决偏差见[视觉模块](../vision.md)。PC/板端同图回放及文件哈希已有验证，不是实物精度验收。当前仍需关注近左边界约6mm视觉差异及下探动态，后续控制调整由用户决定。
