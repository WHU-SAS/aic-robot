## 目标与取舍

从语音启动到用户指定的夹住成功判据满足，任务负责观察、接近、定位、抓取和恢复；6号实际开始闭合至抬升成功暂停视觉，空夹／失夹恢复后再观察。第一版车停臂抓；取消纠偏次数上限，不新增最终失败条件。固定目标仍追求一次停车、一次夹取，首次停车入窗超过95%仍是未验收的现场目标；人为移块引起的重新追踪与固定目标纠偏分开统计。

粗定位每帧估计方向与桌面粗距离，也记录可见性和移动趋势；精定位按需同时校正位置、方向和夹持面。停车目的地继续按当前10mm内缩窗口的近端四分之一计算，原前进速度曲线保持。新的调度负载可能改变实际精测耗时，触发距离须后续结合板端计时复核，不能仅凭旧参数保证2.0～2.5秒。

## 一台相机与分步调度

整车持有唯一相机，抓取阶段不关闭相机或另开一套。追踪候选先启动相机流与MediaManager，再开音频，默认32块预热期间小步完成原30帧／30ms相机预热及五组视觉／控制预加载，全部就绪并reset识别器后才监听。监听与多轮任务复用此相机及固定投影；Tracker、目标状态、任务、UART及底盘同步每轮新建，首轮精测不再承担预导入。首次上电仍有准备时间，不发送车臂动作；未计板端新启动时间，不将假音频队列或PC计时当作提速实测。独立和旧单次入口保持原生命周期。用户最新选择精测优先并按预算穿插观察：精测持有原图，只有累计计算时间足以支付额外观察时才取新粗帧，不能恢复固定10Hz穿插。普通行驶及6号闭合前的机械臂执行仍以100ms粗观察为目标，静止规划为250ms；6号实际开始闭合后至抬升成功暂停取图、粗测和视觉目标更新，空夹或失夹进入恢复后重新观察；规划仍在粗观察之间推进。等待行进精测时，仍根据已有精测锚点或可靠粗距离、编码器及原滑行模型推进距离控制；轮速调整占用原250ms续租槽，不能只续HB而不检查剩距。精测按20ms软片连续推进，不因已经错过的相机截止时刻饿死，也不让每个数学小步骤额外睡眠。拍照指RAM内取帧，不逐帧JPEG录像或写SD。精测独立保存原JPEG95/BGR，新帧不覆盖正在计算的照片。

精测穿插预算只累计本轮`session.start/advance`的实际计算时间F，额外取图、粗检测和变化判断的整段成本计为C。下一次观察仅在`C＋预留成本≤0.1×F`时准入；预留初值60ms，按已测成本峰值上调。预算不足继续精测，不等待凑足固定频率；若预留观察时间会挤占原心跳／STATUS刷新，则暂缓该帧、回原轮次先完成必要通信。穿插入口不额外查询STATUS、写SD或执行完整车控／机械臂周期。移动帧须待原有真实反馈覆盖拍摄时刻再判断；过期帧保持未知，不把旧编码器或旧图伪装成新证据。比率设为0可作纯精测对照。记录计算量、观察量、次数和超预留，不能将预算计数或有限样本最大值当作端到端硬保证。10%约束固定目标下新增观察的成本；目标移动导致取消重算的耗时另计。实际端到端增量还受原心跳相位和运行时开销影响，可能略高于预算账目，仍待板端同图对照。

只要仍有精测或规划可推进，20ms后台片后立即进入下一片，省去固定5ms空等；机械臂执行、疑似变化、故障和无工作等待保留5ms。有效行进精测完成当轮先读取STATUS并下发补偿后的距离命令，不等待新粗帧；停车精测消费及首次悬停前仍取新粗帧核验；穿插观察受累计预算和不可抢占的原生调用限制，短精测可能一帧也不插，仍可能在计算结束后才发现移块。逆解的顶点高度计算保留全部935个夹爪顶点及原求和顺序，仅移出循环内常量、减少切片和函数调用；每条臂日志只序列化一次，stdout与SD复用同一文本，事件及验证均保留。

底盘`STATUS`返回两轮编码器、运行和输出状态。普通运动及尚未确认停车时保持原反馈节奏；行进精测暂停相机时，用250ms刷新HB的真实应答更新编码器，不能伪造新轮程；停车精测及确认停车后独立按500ms查询STATUS，不再与每张粗图绑定。行进精测接管只先读取最新底盘状态，不先拍新粗图；停车结果消费、规划完成后的首次悬停前仍各取最新粗帧和底盘状态。复用状态保留其原查询时间，不当作新读数；累计停车参考及目标版本规则沿用。

同时只推进当前需要的一项精测。RAM按用途保留最近一张行进精图和一张停车精图，跨目标版本仍留作诊断；同用途新图替换旧图，另可有正在计算的一张。取消旧工作立即撤销其控制权限，保留的历史图不因诊断留存而恢复导航、停车或交臂资格；采集时刻和原版本不改写。任务结束后归档仍保留的材料，不为中间图归档额外停车，不删除以前已落盘的报告素材或困难集。精测、规划和串口仍有不可抢占的原子操作，软预算不等于硬实时保证；记录真实采图间隔、最长观察空档和计算耗时，不能声称当前已经严格10Hz。

## 目标状态和结果有效性

- 原拍摄时刻、帧号、目标版本和编码器参考成套保存，计算完成时间不替代拍摄时间。
- 精测原帧同时保留粗测基线。粗框代理与精测几何中心不是同一参考点，不能直接相减；静止时比较局部粗框两侧共同平移，证据只在既有粗测时效的短窗口内累计。尚未建立精测距离时，正常连续接近的合格方块线索明显跳位属于`tracking_update`，继续差速跟随，撤销旧精测并按需边走重测，不进入停稳或全局搜索。大像素变化先考虑两轮行程解释的自身转弯，避免每张迟到精图都被正常车身运动抢先作废。普通运动模型偏差仍只记`motion_model_uncertain`；明确出画照常撤权。静止及抓取阶段保留原移位确认规则。单边分割扩张及正常尺寸增长不直接当移位，粗代理距离矛盾仅作诊断，不让首帧系统偏差无限累计成外移。低于噪声的极慢移、整块mask漂移及遮挡内移走后原样放回仍不可可靠区分。
- 粗测区分可见证据与有效桌面距离。触边、部分遮挡、疑似悬空仍可留下方位线索，不能强行输出有效桌面毫米数。
- 每帧只选择一次粗候选：框、像素中心、粗距离、关联证据和确认数必须同源。无关联、歧义、丢失或过期打断确认链；用户最新选择完整追踪包的新候选单帧生效，`navigation_confirmed`在首张唯一且有效的桌面测量后成立；初次接近、搜索新方向、精测查询和重新接管使用这一帧数。静止及抓取阶段异常移位仍按原两帧确认，连续丢失进入搜索仍为三帧，分别配置。旧独立对照入口保持原三帧。`association_confirmations`仅表示同一可见线索连续出现，几何失效时也可累计，用于请求检查，不授权新行程。可测候选的严格内含小片段可被外层实测框吸收为重复线索，不合并像素或补尺寸；独立蓝物体仍保留歧义。
- 方向、查询、身份和距离分别授权。当前唯一且形状合格的蓝色线索可提供搜索方向；稳定候选的`precise_candidate`可请求停车拍新精图，即使尚不能证明它是原目标或桌面距离无效。它本身不更新原目标运动参考、不撤销旧精测，也不建立导航或抓取坐标。弱线索须有与可信完整框连续的位置／尺度支持，才作为原目标的移动或出画证据；陌生小蓝片保持未知。新完整精测仍须通过原同帧后验关联，才可建立新几何。
- 状态区分一致、未知、疑似变化和确认变化。单帧掉框或粗框跳动不直接触发回位；正常跟随资料更新也会换目标版本并撤销旧精测权限，这不要求停车；静止确认移动或明确移出时，撤销旧距离和未发抓取计划；车身累计移动或机械臂恢复等原有失效来源仍保留。
- 有效行进精测仍须通过原图同帧目标关联、请求身份及时间检查；随后立即STATUS补偿并发SPEED／STOP，之后才恢复粗观察。已经绑定的完整定位或测距候选是本段距离依据；单帧`precise_consistency`偏差仅记未知，不撤销它。运动中确认外移须同时有可信关联、相容尺寸、两侧共同画面平移及扣除编码器自运动后的连续一致残差，沿用原两帧／像素门槛和500ms窗口；只有模型偏差、粗距离改变、歧义或陌生小片不算确认。大幅同尺寸移位后保持原位也可连续确认；尺寸突变或关联不清则先走完已知余程再观察，不宣称能凭颜色证明物理身份。正常距离STOP后的停稳阶段由新静图接管，轮速归零不能让旧行进锚点再补走。MCU已到点时迟到行进图不恢复行驶或交臂，必须新静测；停车精测和首次悬停保留新粗帧／STATUS及原累计静止检查。
- 逆解规划使用`begin_from_observation_steps`，目标变化时关闭旧规划生成器；它尚未发出舵机目标，取消不额外归位。规划最终返回惰性执行器，仍取新粗帧复核后才发首次悬停。已经发出动作的执行器则必须按准备位2覆盖恢复，关闭UART不能代替实体中断。
- 用户明确选择规划一律以准备位2的命令角度为起始参考，不管机械臂实际是否在该位置；初轮和恢复轮均不再为选解读取六轴。`planning_reference`标记`measured=False`，不冒充实际到位。执行阶段的反馈读取、到位及夹住判据保留；先验证完整抓取姿态，再发已有悬停目标。
- 用户最新规则：6号实际闭合起至抬升成功不再取图、粗测或更新视觉目标，不以画面变化撤销抓取。只用原舵机反馈和底盘STATUS／累计轮程检查；空夹或失夹进入恢复后重新启用粗定位。反馈保留真实采样轴和时刻。
- 闭合前的疑似外移继续暂停未发出的动作，确认移位后撤销旧计划；6号闭合后不再等待画面解除疑似，也不以闭合前残留的`suspected`阻断抬升或成功。是否夹到及抬升成功只按原舵机判据确认，底盘移动检查仍保留。

## 粗精配合与异常恢复

| 情况 | 下一步 |
| --- | --- |
| 无有效精测，目标可关联且桌面距离可用 | 粗方向和粗距离共同引导接近，合适时触发精测。 |
| 精测计算中车在走、目标不动 | 已知剩距继续按编码器递减，沿原曲线调速；SPEED/HB复用原续租时槽。剩距耗尽即停车，不因精测仍在算而继续前进。 |
| 行进精测期间方块移到视野内新位置 | 穿插粗帧或完成后的新帧发现变化时，剥离过时精测，继续跟随当前可用目标并按需重测，不刻意停车。 |
| 静止精测期间方块移动 | 旧图不再交臂，保持停车重新观察定位；遮挡／歧义保持未知。 |
| 暂时遮挡，未确认移动 | 有可靠旧距离则走完已确定剩距后停车观察；推算点不能授权抓取。 |
| 明确移出画面 | 作废追向旧目标的计划，朝最后消失方向寻找；搜索中持续观察，首帧唯一有效候选即可恢复导航。 |
| 一直移动，精测反复过时 | 优先粗跟踪，位置变化缓和且确有精度需求时再精测，不堆旧照片队列。 |
| 停车精测失败 | 保留同版本近处恢复上下文；停稳后换角度或小幅挪位，再拍新图，不在相同视角无限重复同样计算。关联的裁边／无粗距离线索不直接升级全局搜索。 |
| 验窗或机械臂规划期间移动 | 旧验窗图不再有交臂权限；首次动作前检查最新观察。 |
| 悬停/下探/200ms分开发包期间移位 | 车保持停，臂按已确认位2覆盖恢复，清除未发包；从目标实际发出500ms后允许重新定位，不等实际回位。 |
| 已发送6号闭合目标 | 暂停采图、粗定位及视觉外移判断；沿用原6号反馈和五次稳定／Δ30判据。 |
| 恢复期间再次变化 | 合并重复失效事件，不反复发位2或重置500ms；新定位使用最新观察。 |
| 夹爪自遮挡 | 保留未知，不因自遮挡直接回位；明确出现于另一处的关联证据另行处理。 |
| 正常夹住并抬升 | 继续暂停视觉，仅按原五轴到位及6号夹持稳定规则确认成功，不因画面变化开爪归位。 |
| 空夹/失夹 | 按已确认Δ规则恢复观察和追踪，不结束整项任务。 |
| 抬离桌面/部分出框 | 继续记录蓝色和方位证据，桌面距离不可用时不伪造毫米数；取得有效几何后再接近/抓取。 |
| 多个蓝物体/关联不明 | 保留歧义，不只选最大蓝块冒充原目标；重新确认关联及物理面。 |

行进精测失败后的近处重测、目标移近后的重新精测，也必须受已有剩余行程约束。JPEG压缩或原生数学调用不能抢占；它们每次返回后，若已耗尽行程，就先交还主循环发STOP，不先推进另一段计算或拍新图。停车前的moving结果此后不恢复前进，也不交臂；按原停稳条件取得新静态精图再验窗。该修正不改变巡航／收尾速度、停车窗或既有时限，也不保证不可抢占调用内部的精确停车。

精测只在精度确有需要时执行：进入近区、确认目标变化后需要重新建立准确位置、静止时粗观察确认变化、换位后重定位、停车验窗和抓取所需几何不足。行进结果可服务距离/方向/停车规划；停车后的同一完整静态结果同时验窗并提供机械臂位置及夹持方向，不重复做同样精测。有限测距候选、粗代理及编码器推算都不能变成抓取坐标。

新追踪包显式采用`static_localization_policy=shared_side_only`：停车图可用该图唯一关联粗候选的原`bbox`提示共享侧面搜索，继续完成四边、2px及桌面约束验证，保留其原有小恢复。这个提示不代替完整边缘测量或完成后的严格同帧关联。不能定位时返回真实拒绝信息，交给换角度／小幅挪位流程继续看，不在同一张图里长时间穷举旧恢复。只有该静测策略启用搜索提示；未配置该策略的独立、旧单次和离线入口保留完整恢复及原搜索行为。

正常流程不能被异常判断反复打断。行进精测未获得距离时继续使用已有接近依据，在下一张有效粗帧重试，不因本次精测失败主动停车；短暂粗测未知时可按编码器传播最后可靠粗观测，当前可见像素仍可修方向。仅有粗缓存时最多走完它已确定的剩余粗行程，然后停车观察，缓存不是精测或抓取坐标。

停车后的测量失败不等同于目标丢失。近处恢复单独保留同版本历史几何及原采集时刻，编码器传播只供选择恢复方向；新版底部视野恢复按上述连续慢退处理，不用历史点直接授权抓取，也不每10mm重复失败精测。恢复后仍须重新停稳并取得新静态完整测量。确认移位、退出或版本变化撤销旧几何及抓取权限；同次底部恢复的物理起点、累计预算和耗尽状态单独保留。未知或暂时遮挡不伪造确认变化。

除上述底部视野恢复尚未完成的情况外，停车精测计算、抓取规划或首次悬停发出前，一帧未知只暂停交接，不永久污染该次成功精测，也不立即销毁未发计划。同版本恢复唯一关联、观察一致且车身始终未动时复用原图；确认移位、出画、车身移动、原有结果时效过期，或重现后仍无法确认几何一致时，才重新定位。首次动作前连续看不到目标达到既有搜索确认条件时，释放未发计划再进入观察／搜索，不能被暂停的计划永远占住流程。机械臂已动作后的自遮挡仍按执行阶段处理，不套用首次动作前的搜索。

全局搜索使用有符号`FOLLOW`低速连续转动，默认两轮−20/+20mm/s或+20/−20mm/s；转动中用`SPEED`更新方向、`HB`续通信，不再每10°结束一段ARC。新版优先当前可信且已关联的目标方位，其他可测蓝块不能盖过该目标；失去原关联后，新候选按用户最新选择在首帧即可改写搜索方向，但仍需通过原单帧形状／唯一性条件；新候选接管先撤销旧精测权限。相同目标的当前可信线索仍优先，历史消失方向供暂无线索时使用。取得合格候选后真正退出全局搜索：可导航则接近，距离尚不可用则进入`visual_tracking`局部观察并请求新静测。此时精测失败仅触发原10°局部换角，不等同于再次丢失；一两帧未知先停，确认丢失后才回全局搜索。身份和毫米导航仍按各自标准确认。

搜索进度属于一次持续的搜索过程，不因短暂蓝色闪现、再次未知或目标版本更新而重置。可靠底部丢失优先进入上述连续慢退，完整视野恢复前不先转圈，也不被可用粗距离提前带回前进分支；其他方向保留连续转向搜索。精测仍失败则保留进度，依据实际编码器完成换角后再检查。连续搜索沿用MCU原`FOLLOW`单次20秒总时限，`SPEED/HB`不延长它；到限停车后重新观察、停稳并按当前线索继续，不能承诺永久不间断。失联、按钮停止和拒绝响应沿用原等待语义，未增加任务放弃条件。可靠旧路线遇短遮挡仍可走完已知剩距。

诊断只在RAM保留最近64个目标、精测、车控与交臂转换，记录停车原因、原图到定位及首次悬停耗时；任务结束或正常中断时并入已有运行记录，不逐帧写SD。断电会丢失尚未归档的记录；异常后保持独立供电、先接回USB读取，再重启。粗颜色框的整体漂移与同色物体慢移仍可能不可区分，不能把粗测运动判断描述为物体身份或移动真值。

留存的精图同时保存原同帧`paired_coarse`框、证据、确认状态及实际`localization_bbox_px`入参。派生搜索ROI不能反推原输入框，也不能只凭同帧号认定粗、精选中了同一物体。上版`0d5e760691b3ba45`的已知故障链为成功行进精测正常消费、停车精测拒绝、换角后清除接近参考，随后底部裁边误触发全局搜索；已用真实观测字段和明确合成的控制序列回归，缺失原图的部分不称视觉回放。更早异常的往复动作及候选关联材料同样留在异常目录，不混作本轮实物验收。

JPEG、解码、求解器、相机或串口等运行异常先尝试`STOP`，再保存诊断并报告`fault_wait`；即使本地运行状态可能因ACK丢失而过期，也先尝试停止。异常／取消记录为`processing_interrupted`等真实状态，不伪装成正常的`no_complete_face`，也不自动继续发非零车臂命令。正常视觉拒绝才进入原换视角恢复；运行故障保留原处理和人工恢复语义。用户报告右移后左转约180°停下的现场日志保存在本机`search_half_turn_01/`；单帧蓝片污染搜索方向的路径已离线复现，但停转前电机状态和原异常缺失，实际停转原因尚未定因。首个故障及其STOP前状态、真实STOP应答单独留档，后续IDE中断不能覆盖它；故障后阶段明确为`fault_wait`并停止相机／车控推进，避免显示仍在搜索。

行进测距和停车完整精测在完成后统一检查`target_association`，再交底盘和目标记忆使用。检查原帧唯一关联粗候选的蓝像素质心与精测实际选用姿态的完整20mm方块投影范围，不要求质心落在所选侧面内，保留仅亮顶面被粗测选中的正常情况。姿态支持来自实际选面，测距审计中的其他候选面不能代替选面。没有唯一支持时返回`unknown`，原成功解及审计留档；下游收到清除XYZ和测距候选的失败观测，不建立锚点或交臂，继续原观察恢复流程。此检查不重拍、不重算PnP、不改原几何门槛；2px关联容差是本轮选择的像素判别参数，不能解释为原重投影RMS保证的最大误差。投影重叠的同色物体仍无法仅凭此必要条件证明身份。

当前正式追踪不再使用闭合／抬升的持物视觉关联区或FK预测：6号实际开始闭合后暂停软件取图、粗测与Memory视觉更新，硬件相机流可保持。暂停不等于停止舵机反馈或原底盘STATUS检查；抬升成功结束任务并保持夹持，未夹到或中途失夹则按原准备位2恢复并重新观察、定位、抓取。闭合前的悬停／下探继续观察，真实目标移走仍可撤销未执行抓取。关闭视觉期间不会通过画面发现人为抢夺，只依据原6号反馈识别失夹；原Δ30、五次闭合稳定、抬升±10／±1及200ms规则不变。

静态流程的前向纠偏：新静态精测显示纵向仍在窗口远边界外时，继续使用已有70→50mm/s连续速度曲线、实时粗方向和编码器剩距，不整段改用主轮15mm/s短ARC；最终仍拍新静态图验窗。同一纵向窗口内仅侧偏、需要后退或原地转向时保留有符号ARC，避免为极短前进距离额外启停。初始近起点仍先静态定位，不盲发巡航。
