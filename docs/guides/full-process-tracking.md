# 全流程追踪升级

2026-11-02用户批准的开发方案，已形成离线候选并完成模拟、原图对照及打包验证，尚未部署；板端运行版本以本机安装记录为准。机械臂契约见[分步抓取接口](arm-tracking.md)，整车约定见[完整任务](robot-task.md)。

## 目标与取舍

从语音启动到用户指定的夹住成功判据满足，任务持续观察、接近、定位、抓取和恢复。第一版车停臂抓；取消纠偏次数上限，不新增最终失败条件。固定目标仍追求一次停车、一次夹取，首次停车入窗超过95%仍是未验收的现场目标；人为移块引起的重新追踪与固定目标纠偏分开统计。

粗定位每帧估计方向与桌面粗距离，也记录可见性和移动趋势；精定位按需同时校正位置、方向和夹持面。正常近处细测、停车目的地、10mm内缩窗口及运动参数沿用当前基线。新的调度负载可能改变实际精测耗时，触发距离须后续结合板端计时复核，不能仅凭旧参数保证2.0～2.5秒。

## 一台相机与分步调度

整车持有唯一相机，抓取阶段不关闭相机或另开一套。以100ms为粗观察目标周期：取新帧、粗测、处理目标变化，然后服务底盘通信及到期机械臂步骤，剩余时间推进精测或机械臂逆解规划。后台按20ms软时间片推进多个廉价yield，遇下一次观察截止时刻就让出，不让每个数学小步骤都额外支付一次睡眠。拍照指RAM内取帧，不逐帧JPEG录像或写SD。精测独立保存原JPEG95/BGR，新帧不覆盖正在计算的照片。

同时只保留当前需要的一项精测。用户明确允许释放无用的旧精测原图：确认目标变化时撤销旧工作并释放其图像，同一目标的新结果替换同用途旧图；RAM只保留当前目标最新行进图与最新静态图及正在计算的那一张，任务结束后保存最终仍有用的素材，不为中间图归档额外停车。不删除以前已归档的报告素材或困难集。精测、规划和串口仍有不可抢占的原子操作，软预算不等于硬实时保证；记录真实采图间隔、最长观察空档和计算耗时，不能声称当前已经严格10Hz。

## 目标状态和结果有效性

- 原拍摄时刻、帧号、目标版本和编码器参考成套保存，计算完成时间不替代拍摄时间。
- 精测原帧同时保留粗测基线。粗框代理与精测几何中心不是同一参考点，不能直接相减；先传播车自身运动，再比较同类粗观测的相对变化。
- 粗测区分可见证据与有效桌面距离。触边、部分遮挡、疑似悬空仍可留下方位线索，不能强行输出有效桌面毫米数。
- 状态区分一致、未知、疑似变化和确认变化。单帧掉框或粗框跳动不直接触发回位；确认移动或明确移出才更新目标版本、作废旧距离和未发抓取计划。
- 精测完成、机械臂规划完成及每次阶段发包前核对当前目标版本。旧版本结果即使成功，或物块后来回到原位置，也不自动恢复有效。
- 逆解规划使用`begin_from_observation_steps`，目标变化时关闭旧规划生成器；它尚未发出舵机目标，取消不额外归位。规划最终返回惰性执行器，仍取新粗帧复核后才发首次悬停。已经发出动作的执行器则必须按准备位2覆盖恢复，关闭UART不能代替实体中断。
- 夹住后按持物阶段解释视觉。方块随臂正常抬升不能当作桌面目标被人为移走；自遮挡表示未知。机械臂反馈须看实际采样轴和时刻，不能把旧轴读数当新数据。
- 已到达的疑似外移证据优先于整车成功提交。此时臂仍采样、复核原200ms判据，Δ＜30照常立即恢复；仅暂不提交`succeeded`。下一帧若确认移位则覆盖恢复，疑似解除则按最新有效采样放行，不额外增加固定等待。自遮挡未知不当作疑似外移。

## 粗精配合与异常恢复

| 情况 | 下一步 |
| --- | --- |
| 无有效精测，目标可关联且桌面距离可用 | 粗方向和粗距离共同引导接近，合适时触发精测。 |
| 精测计算中车在走、目标不动 | 粗测继续观察，编码器补偿拍照后的平移和转向；完成结果同时校正方向和距离。 |
| 精测中确认目标移位 | 作废旧锚点和工作结果，粗跟新位置，按当前需要重新精测。 |
| 暂时遮挡，未确认移动 | 有可靠旧距离则走完已确定剩距后停车观察；推算点不能授权抓取。 |
| 明确移出画面 | 作废追向旧目标的计划，朝最后消失方向寻找；搜索中持续观察，重获即结束搜索。 |
| 一直移动，精测反复过时 | 优先粗跟踪，位置变化缓和且确有精度需求时再精测，不堆旧照片队列。 |
| 停车精测失败 | 继续观察；换角度或小幅挪位后重测，不在相同视角无限重复同样计算。 |
| 验窗或机械臂规划期间移动 | 旧验窗图不再有交臂权限；首次动作前检查最新观察。 |
| 悬停/下探/200ms分开发包期间移位 | 车保持停，臂按已确认位2覆盖恢复，清除未发包；从目标实际发出500ms后允许重新定位，不等实际回位。 |
| 恢复期间再次变化 | 合并重复失效事件，不反复发位2或重置500ms；新定位使用最新观察。 |
| 夹爪自遮挡 | 保留未知，不因自遮挡直接回位；明确出现于另一处的关联证据另行处理。 |
| 正常夹住并抬升 | 切换持物监视，结合阶段和6号证据，不继续套用桌面静止模型。 |
| 空夹/失夹 | 按已确认Δ规则恢复观察和追踪，不结束整项任务。 |
| 抬离桌面/部分出框 | 继续记录蓝色和方位证据，桌面距离不可用时不伪造毫米数；取得有效几何后再接近/抓取。 |
| 多个蓝物体/关联不明 | 保留歧义，不只选最大蓝块冒充原目标；重新确认关联及物理面。 |

精测只在精度确有需要时执行：进入近区、确认目标变化后需要重新建立准确位置、粗观察与预测持续矛盾、换位后重定位、停车验窗和抓取所需几何不足。行进结果可服务距离/方向/停车规划；停车后的同一完整静态结果同时验窗并提供机械臂位置及夹持方向，不重复做同样精测。有限测距候选、粗代理及编码器推算都不能变成抓取坐标。

## 离线开发和审查

目标记忆、粗观察证据和小车分步控制由独立代理并行实现；整车统一调度负责版本、相机、精测和臂接口交接。机械臂Agent复核方案并维护其分步执行器与共享精测可让出部分。使用模拟时钟、假串口、运动序列及原图回放验证旧结果失效、未知/移位区分、重复恢复合并、无次数终止、正常持物和固定目标流程。

新动作与判断参数集中配置，属于离线初始候选，不宣称现场已调好。既有底盘停止原因仍由上层解释，通信/执行异常不盲发动作，也不在本轮追加整项任务的最终放弃规则。已确定的实现问题自行修正；涉及未确定行为取舍时再交用户决定。板端频率、观测噪声、搜索/撤回轨迹和整车成功率留待后续联调。

构建新候选使用`./scripts/deploy-robot --tracking`，默认无此选项仍构建原单次流程作对照；构建不访问硬件。只有后续明确安装并激活才改变板端入口。天猛星ARC固件已单独下载并做零输出检查，不代表整车追踪版已部署。

持物视觉关联使用新鲜六轴反馈的FK夹持区域作宽松参考，不把模型点当物块实测。两帧唯一蓝候选远离该区域才可能确认外移；多个同色物体无法仅凭颜色证明身份，歧义和自遮挡保持未知。实际观察最长空档及模型偏差须现场复核。

首次上板先做静止的取图/精测/规划交织计时，确认最大观察空档及串口间隔，再安排固定目标整车运行。之后逐项测试精测中移块/遮挡/出视野、规划时移块、下探分包时移块、正常抬升及空夹/抢走恢复；保存首次入窗、实际发起抓取次数及恢复原因，不能把模拟通过写成现场成功率。
