## 目标与取舍

从语音启动到用户指定的夹住成功判据满足，任务持续观察、接近、定位、抓取和恢复。第一版车停臂抓；取消纠偏次数上限，不新增最终失败条件。固定目标仍追求一次停车、一次夹取，首次停车入窗超过95%仍是未验收的现场目标；人为移块引起的重新追踪与固定目标纠偏分开统计。

粗定位每帧估计方向与桌面粗距离，也记录可见性和移动趋势；精定位按需同时校正位置、方向和夹持面。停车目的地继续按当前10mm内缩窗口的近端四分之一计算，原前进速度曲线保持。新的调度负载可能改变实际精测耗时，触发距离须后续结合板端计时复核，不能仅凭旧参数保证2.0～2.5秒。

## 一台相机与分步调度

整车持有唯一相机，抓取阶段不关闭相机或另开一套。追踪入口在首次语音监听前完成相机初始化及原30帧预热，监听与多轮任务复用此相机；每轮唤醒后不再重复准备。首次上电仍有准备时间，不发送车臂动作。独立和旧单次入口保持原生命周期。用户最新选择精测优先：任一行进／停车精测开始后，暂停粗取图和粗分析，算完立即恢复。普通行驶和机械臂执行仍以100ms粗观察为目标，静止规划为250ms；规划仍在粗观察之间推进。精测按20ms软片连续推进，不因已经错过的相机截止时刻饿死，也不让每个数学小步骤额外睡眠。拍照指RAM内取帧，不逐帧JPEG录像或写SD。精测独立保存原JPEG95/BGR，新帧不覆盖正在计算的照片。

只要仍有精测或规划可推进，20ms后台片后立即进入下一片，省去固定5ms空等；机械臂执行、疑似变化、故障和无工作等待保留5ms。精测完成后的结果消费及首次悬停前，仍分别取新粗帧核验；精测期间无法实时发现移块，这是本次缩短精测延迟的明确取舍。逆解的顶点高度计算保留全部935个夹爪顶点及原求和顺序，仅移出循环内常量、减少切片和函数调用；每条臂日志只序列化一次，stdout与SD复用同一文本，事件及验证均保留。

底盘`STATUS`返回两轮编码器、运行和输出状态。普通运动及尚未确认停车时保持原反馈节奏；行进精测暂停相机时，用250ms刷新HB的真实应答更新编码器，不能伪造新轮程；停车精测及确认停车后独立按500ms查询STATUS，不再与每张粗图绑定。精测结果消费、规划完成后的首次悬停前仍各取最新粗帧和底盘状态。复用状态保留其原查询时间，不当作新读数；累计停车参考及目标版本规则沿用。

同时只推进当前需要的一项精测。RAM按用途保留最近一张行进精图和一张停车精图，跨目标版本仍留作诊断；同用途新图替换旧图，另可有正在计算的一张。取消旧工作立即撤销其控制权限，保留的历史图不因诊断留存而恢复导航、停车或交臂资格；采集时刻和原版本不改写。任务结束后归档仍保留的材料，不为中间图归档额外停车，不删除以前已落盘的报告素材或困难集。精测、规划和串口仍有不可抢占的原子操作，软预算不等于硬实时保证；记录真实采图间隔、最长观察空档和计算耗时，不能声称当前已经严格10Hz。

## 目标状态和结果有效性

- 原拍摄时刻、帧号、目标版本和编码器参考成套保存，计算完成时间不替代拍摄时间。
- 精测原帧同时保留粗测基线。粗框代理与精测几何中心不是同一参考点，不能直接相减；静止时比较局部粗框两侧共同平移，证据只在既有粗测时效的短窗口内累计。运动中仍计算轮程传播和画面差异，但差异仅记为`motion_model_uncertain`，不直接当作目标移动、不把这段疑虑积攒到停车后；避免轮程/打滑/分割模型误差反复作废精图。明显原图跳位沿用既有关联门限并经两帧确认，明确出画照常作废目标；视野内缓慢移块的作废可能延迟到新静态精测，粗方向仍随当前图更新。单边分割扩张及正常尺寸增长不直接当移位，粗代理距离矛盾仅作诊断，不让首帧系统偏差无限累计成外移。低于噪声的极慢移、整块mask漂移及遮挡内移走后原样放回仍不可可靠区分。
- 粗测区分可见证据与有效桌面距离。触边、部分遮挡、疑似悬空仍可留下方位线索，不能强行输出有效桌面毫米数。
- 每帧只选择一次粗候选：框、像素中心、粗距离、关联证据和确认数必须同源。无关联、歧义、丢失或过期打断确认链；用户最新选择完整追踪包的新候选单帧生效，`navigation_confirmed`在首张唯一且有效的桌面测量后成立；初次接近、搜索新方向、精测查询和重新接管使用这一帧数。异常移位仍按原两帧确认，连续丢失进入搜索仍为三帧，分别配置。旧独立对照入口保持原三帧。`association_confirmations`仅表示同一可见线索连续出现，几何失效时也可累计，用于请求检查，不授权新行程。可测候选的严格内含小片段可被外层实测框吸收为重复线索，不合并像素或补尺寸；独立蓝物体仍保留歧义。
- 方向、查询、身份和距离分别授权。当前唯一且形状合格的蓝色线索可提供搜索方向；稳定候选的`precise_candidate`可请求停车拍新精图，即使尚不能证明它是原目标或桌面距离无效。它本身不更新原目标运动参考、不撤销旧精测，也不建立导航或抓取坐标。弱线索须有与可信完整框连续的位置／尺度支持，才作为原目标的移动或出画证据；陌生小蓝片保持未知。新完整精测仍须通过原同帧后验关联，才可建立新几何。
- 状态区分一致、未知、疑似变化和确认变化。单帧掉框或粗框跳动不直接触发回位；视觉确认移动或明确移出时更新目标版本、作废旧距离和未发抓取计划；车身累计移动或机械臂恢复等原有失效来源仍保留。
- 精测完成先恢复一张当前粗图及STATUS，再核对同帧原图关联、当前原始线索与轮程传播是否矛盾；暂停造成原生确认链过期重置为1时，也不能让明显移位的旧完整解或仅测距解恢复控制权限。此检查只撤销矛盾结果，未知不冒充确认移动。机械臂规划完成及每次阶段发包前继续核对当前目标版本。一致性比较的轮程截止于新粗图拍摄时刻，排除该图之后的通信和计算行程；实际行车剩距另补偿到决策当前时刻。旧版本结果即使成功，或物块后来回到原位置，也不自动恢复有效。
- 逆解规划使用`begin_from_observation_steps`，目标变化时关闭旧规划生成器；它尚未发出舵机目标，取消不额外归位。规划最终返回惰性执行器，仍取新粗帧复核后才发首次悬停。已经发出动作的执行器则必须按准备位2覆盖恢复，关闭UART不能代替实体中断。
- 用户明确选择规划一律以准备位2的命令角度为起始参考，不管机械臂实际是否在该位置；初轮和恢复轮均不再为选解读取六轴。`planning_reference`标记`measured=False`，不冒充实际到位。执行阶段的反馈读取、到位及夹住判据保留；先验证完整抓取姿态，再发已有悬停目标。
- 夹住后按持物阶段解释视觉。方块随臂正常抬升不能当作桌面目标被人为移走；自遮挡表示未知。机械臂反馈须看实际采样轴和时刻，不能把旧轴读数当新数据。
- 已到达的疑似外移证据优先于整车成功提交。此时臂仍采样、复核原200ms判据，Δ＜30照常立即恢复；仅暂不提交`succeeded`。下一帧若确认移位则覆盖恢复，疑似解除则按最新有效采样放行，不额外增加固定等待。自遮挡未知不当作疑似外移。

## 粗精配合与异常恢复

| 情况 | 下一步 |
| --- | --- |
| 无有效精测，目标可关联且桌面距离可用 | 粗方向和粗距离共同引导接近，合适时触发精测。 |
| 精测计算中车在走、目标不动 | 暂停粗取图，维持现有车控并采集真实HB编码器；算完恢复粗测，按拍照至当前轮程补偿位置及方向。 |
| 精测期间方块被移走 | 计算期间不观察；完成后先取当前粗帧。明确矛盾的旧结果不得导航／交臂，重新观察和定位；遮挡或歧义保持未知，只允许原可靠剩距语义。 |
| 暂时遮挡，未确认移动 | 有可靠旧距离则走完已确定剩距后停车观察；推算点不能授权抓取。 |
| 明确移出画面 | 作废追向旧目标的计划，朝最后消失方向寻找；搜索中持续观察，首帧唯一有效候选即可恢复导航。 |
| 一直移动，精测反复过时 | 优先粗跟踪，位置变化缓和且确有精度需求时再精测，不堆旧照片队列。 |
| 停车精测失败 | 保留同版本近处恢复上下文；停稳后换角度或小幅挪位，再拍新图，不在相同视角无限重复同样计算。关联的裁边／无粗距离线索不直接升级全局搜索。 |
| 验窗或机械臂规划期间移动 | 旧验窗图不再有交臂权限；首次动作前检查最新观察。 |
| 悬停/下探/200ms分开发包期间移位 | 车保持停，臂按已确认位2覆盖恢复，清除未发包；从目标实际发出500ms后允许重新定位，不等实际回位。 |
| 已发送闭合目标，方块被夹爪挤动或局部遮挡 | 立即采用接触阶段解释，继续原6号反馈和五次稳定／Δ30判据，不用桌面静止残差直接撤销抓取。 |
| 恢复期间再次变化 | 合并重复失效事件，不反复发位2或重置500ms；新定位使用最新观察。 |
| 夹爪自遮挡 | 保留未知，不因自遮挡直接回位；明确出现于另一处的关联证据另行处理。 |
| 正常夹住并抬升 | 切换持物监视，结合阶段和6号证据，不继续套用桌面静止模型。 |
| 空夹/失夹 | 按已确认Δ规则恢复观察和追踪，不结束整项任务。 |
| 抬离桌面/部分出框 | 继续记录蓝色和方位证据，桌面距离不可用时不伪造毫米数；取得有效几何后再接近/抓取。 |
| 多个蓝物体/关联不明 | 保留歧义，不只选最大蓝块冒充原目标；重新确认关联及物理面。 |

精测只在精度确有需要时执行：进入近区、确认目标变化后需要重新建立准确位置、静止时粗观察确认变化、换位后重定位、停车验窗和抓取所需几何不足。行进结果可服务距离/方向/停车规划；停车后的同一完整静态结果同时验窗并提供机械臂位置及夹持方向，不重复做同样精测。有限测距候选、粗代理及编码器推算都不能变成抓取坐标。

新追踪包显式采用`static_localization_policy=shared_side_only`：停车图可用该图唯一关联粗候选的原`bbox`提示共享侧面搜索，继续完成四边、2px及桌面约束验证，保留其原有小恢复。这个提示不代替完整边缘测量或完成后的严格同帧关联。不能定位时返回真实拒绝信息，交给换角度／小幅挪位流程继续看，不在同一张图里长时间穷举旧恢复。只有该静测策略启用搜索提示；未配置该策略的独立、旧单次和离线入口保留完整恢复及原搜索行为。

正常流程不能被异常判断反复打断。行进精测未获得距离时继续使用已有接近依据，在下一张有效粗帧重试，不因本次精测失败主动停车；短暂粗测未知时可按编码器传播最后可靠粗观测，当前可见像素仍可修方向。仅有粗缓存时最多走完它已确定的剩余粗行程，然后停车观察，缓存不是精测或抓取坐标。

停车后的测量失败不等同于目标丢失。近处恢复单独保留同版本历史几何及原采集时刻，编码器传播只供选择恢复方向；新版底部裁边按上述连续慢退处理，不用历史点直接授权抓取，也不每10mm重复失败精测。恢复后仍须重新停稳并取得新静态完整测量。确认移位、退出或版本变化撤销旧参考；未知或暂时遮挡不伪造确认变化。

停车精测计算、抓取规划或首次悬停发出前，一帧未知只暂停交接，不永久污染该次成功精测，也不立即销毁未发计划。同版本恢复唯一关联、观察一致且车身始终未动时复用原图；确认移位、出画、车身移动、原有结果时效过期，或重现后仍无法确认几何一致时，才重新定位。首次动作前连续看不到目标达到既有搜索确认条件时，释放未发计划再进入观察／搜索，不能被暂停的计划永远占住流程。机械臂已动作后的自遮挡仍按执行阶段处理，不套用首次动作前的搜索。

全局搜索使用有符号`FOLLOW`低速连续转动，默认两轮−20/+20mm/s或+20/−20mm/s；转动中用`SPEED`更新方向、`HB`续通信，不再每10°结束一段ARC。新版优先当前可信且已关联的目标方位，其他可测蓝块不能盖过该目标；失去原关联后，新候选按用户最新选择在首帧即可改写搜索方向，但仍需通过原单帧形状／唯一性条件；新候选接管先撤销旧精测权限。相同目标的当前可信线索仍优先，历史消失方向供暂无线索时使用。取得合格候选后真正退出全局搜索：可导航则接近，距离尚不可用则进入`visual_tracking`局部观察并请求新静测。此时精测失败仅触发原10°局部换角，不等同于再次丢失；一两帧未知先停，确认丢失后才回全局搜索。身份和毫米导航仍按各自标准确认。

搜索进度属于一次持续的搜索过程，不因短暂蓝色闪现、再次未知或目标版本更新而重置。确认底部丢失时最多先退一次原10mm，再继续转动；精测仍失败则保留进度，依据实际编码器完成换角后再检查。连续搜索沿用MCU原`FOLLOW`单次20秒总时限，`SPEED/HB`不延长它；到限停车后重新观察、停稳并按当前线索继续，不能承诺永久不间断。失联、按钮停止和拒绝响应沿用原等待语义，未增加任务放弃条件。近处停车恢复与全局搜索分别处理，可靠旧路线遇短遮挡仍可走完已知剩距。

诊断只在RAM保留最近64个目标、精测、车控与交臂转换，记录停车原因、原图到定位及首次悬停耗时；任务结束或正常中断时并入已有运行记录，不逐帧写SD。断电会丢失尚未归档的记录；异常后保持独立供电、先接回USB读取，再重启。粗颜色框的整体漂移与同色物体慢移仍可能不可区分，不能把粗测运动判断描述为物体身份或移动真值。

JPEG、解码、求解器、相机或串口等运行异常先尝试`STOP`，再保存诊断并报告`fault_wait`；即使本地运行状态可能因ACK丢失而过期，也先尝试停止。异常／取消记录为`processing_interrupted`等真实状态，不伪装成正常的`no_complete_face`，也不自动继续发非零车臂命令。正常视觉拒绝才进入原换视角恢复；运行故障保留原处理和人工恢复语义。用户报告右移后左转约180°停下的现场日志保存在本机`search_half_turn_01/`；单帧蓝片污染搜索方向的路径已离线复现，但停转前电机状态和原异常缺失，实际停转原因尚未定因。首个故障及其STOP前状态、真实STOP应答单独留档，后续IDE中断不能覆盖它；故障后阶段明确为`fault_wait`并停止相机／车控推进，避免显示仍在搜索。
