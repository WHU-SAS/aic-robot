## 演示距离

距离定义为：相机标定光心沿桌面法向投影得到的垂足，到方块底面中心的桌面内欧氏距离；不是机械臂Base原点距离，也不是相机到方块的斜距。单位mm，投影到照片上以虚线显示，起点在画外时按画面裁剪并注明。

远处仅有蓝色色块时，底面中心不能精确测得。当前候选标注将色块图像中心投影到桌面上方10mm，再沿桌面法向下移10mm，得到20mm方块的底面中心代理；明确标记Estimated。它不等于色块下边缘与桌面的交点，也不能用作机械臂精定位。以后有通过现有精定位门槛的原始几何中心时，再用该中心求底面中心，保持两种能力区别。

```bash
./scripts/vision tools/analysis/annotate_car_far.py \
  --image data/car/far_capture/实际目录/frame_01.jpg \
  --output data/car/far_annotations
```

输出SVG保留嵌入的原始JPEG，叠加方框、图像中心、蓝色像素面积和距离虚线，另存JSON。PC LAB是近似回放，不代替K230原生检测验证。单张候选不伪装成连续跟踪成功。

如已完成板端保存图回放，可给标注命令加`--native-report data/实际回放目录/result.json`，使用K230原生检测输出；图片必须与报告顺序和文件名一致。重复保存图的连续确认只验证算法状态，不构成真实动态跟踪验证。

## 样本处理与动态定位

### 实时测试命令（小车静止）

```bash
cd /home/xd/Desktop/aic-robot
./scripts/host tools/diagnostics/live_car_tracker.py --execute
```

默认测试120秒，自动打开本机浏览器页面；若没有自动打开，就复制终端的`http://127.0.0.1:端口/`。先退出占用K230的IDE或串口监视器。等终端提示“相机已就绪”、网页出现画面后，按左右移动→远近移动→移出画面几秒→重新放回的顺序操作，先慢后快。绿框为已确认跟踪，橙框为尚在确认，红十字为图像中心；网页显示像素面积、中线偏差、估计平面距离及检测/预览更新率。

网页“结束测试”或Ctrl+C均请求结束并恢复原语音监听；按一次后等待终端打印`RECORD ...`并返回命令行。正常120秒结束也会自动恢复监听。日志、逐帧观测、跟踪状态变化及最后一张带标记的预览保存在`data/car/live_tracking/时间目录/`。可用`--duration 60`改为60秒，`--no-browser`只打印网址。

识别使用当前共享相机的原生RGB565帧、现有色块跟踪器和共享`track_coarse`接口；相机只开一次。USB预览采用已验证的USBDBG二进制JPEG帧缓冲接口，不使用之前慢速逐张下载路径。检测框在K230检测之后绘制，与该画面对应；网页右侧是最近收到的遥测，二者的传输刷新时刻不要求严格同步。检测停更会显示年龄与提示，失去目标不保留旧坐标。

默认100ms为本诊断脚本的最小观测周期，不改整车控制配置，也不承诺10Hz实测帧率。预览传输及SD保存可能影响实测循环耗时，网页分别显示观测更新率与预览接收率。脚本不导入底盘或机械臂控制，不改开机文件；运行时暂时停止原监听，结束后恢复。

首轮实际连续检测记录于`data/car/live_tracking/20261024_151931_079610/`：观测跨度80.631秒、807帧，帧周期99～101ms，单次检测中位数36ms、P95为42ms。用户反馈“基本跟得上，主要在移出或遮挡时丢失”；状态记录包含目标丢失后的重新确认，但没有人工逐帧真值，不能将tracking占比称为识别准确率。退出时原恢复监听失败，补充恢复后已收到voice_ready；现已增加等待旧脚本退出、关闭USB预览及保留完整错误的处理。该次旧脚本**未录下完整视频**，只有日志和最后预览，已据实归档，不能用它还原过去完整画面。

### SD录像素材与读卡器

根据用户“视频留好、可使用读卡器”的要求，新版默认将每帧带检测框/中心的1280×960 JPEG80和时间戳写到`/sdcard/car_live/时间目录/`。终端会打印确切目录；SD卡内对应`car_live/时间目录/`。不将连续原图经USB慢速下载；浏览器预览与本地保存独立，预览刷新慢时，SD仍按实际检测循环保存。`--no-record`显式关闭这项保存。

素材是连续JPEG序列和`frames.jsonl`，**需在PC合成后才是MP4视频**。同时保留标定/阈值快照、实际帧周期和保存耗时；JPEG先保存临时文件再改名，已完成帧不会被覆盖。录制可能降低检测更新率，以本次实测为准。新增录制功能已做离线与编码检查，尚需用户再次现场运行确认，不声称首轮已有完整录像。

结束测试、确认写入及语音恢复完成后，先关机再取出SD卡，用读卡器复制整个时间目录。保留JPEG与JSON，不只挑图片。复制后执行：

```bash
./scripts/vision tools/analysis/export_car_video.py \
  --input data/car/video_sources/实际时间目录 \
  --output data/car/report_assets/blue_cube_live.mp4
```

导出使用实际帧周期重采样，并在时间间隔较长时保持前一帧，避免把保存慢的录像错误地加速；默认10fps，输出时长量化误差小于一帧。MP4加上状态、中心、面积、估计距离和单次检测耗时，保留源帧不修改；同时生成导出参数JSON。已有视频或未完成输出不覆盖。
