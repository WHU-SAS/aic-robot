# 视觉与验证协作案例

近距离视觉是项目的重要瓶颈。我参与的工作包括指出被遗漏的图像特征、要求共用计算结果，以及追问耗时和成功率究竟如何测量。

## 从高光棱线寻找色差之外的突破口

**问题。** 正视和补光照片中，方块两面的颜色接近，反光与背景也会影响分界。AI 围绕颜色差异和候选边界进行修改，正常图片仍会失败。

**我的干预。** 我要求查看失败原图与拟合，指出人眼能看出的高光线可能就是重要边缘线索，提出“找色差还不如找高光线”。我还逐点指出角点偏差，要求解释它与真实轮廓的关系。

**AI 随后的修改。** 算法加入可测高光峰路线：在原图窄剖面上检查两侧均为蓝色、峰值相对两翼突出，再用分布采样拟合棱线，结合外边求解物理面。后续继续使用真实轮廓角点与立方体模型恢复困难姿态。

**结果。** 新路线恢复了部分原先失败的正常图，并成为共享视觉的一部分。高光可能偏离真实物理棱，所以仍需检查测点与原图，不能只凭低重投影误差认定坐标准确。

依据：[精定位算法与当前问题](../guides/vision.md)、[高光与侧面改进 3df7b57](https://github.com/WHU-SAS/aic-robot/commit/3df7b57)、[正视轮廓恢复 cfd14fb](https://github.com/WHU-SAS/aic-robot/commit/cfd14fb)。图示见[高光棱线对照](../showcase/images/08-highlight-edge-localization.png)。

## 一张停车精图同时服务小车与机械臂

**问题。** 小车和机械臂由不同 Agent 推进，如果停车后机械臂再拍一次、再分析一次，会增加等待，也容易出现两套接口和参考点不一致。

**我的干预。** 我要求尽量共用近距离视觉，并明确：小车停车后那张精定位照片，分析出的数据直接作为机械臂夹取信息，机械臂不要额外拍照。

**AI 随后的修改。** 小车与机械臂共用相机、视觉模块与坐标协议；停车静态精图通过完整定位和窗口检查后，把原最终观测交给机械臂。粗测底面代理、行驶测距候选和编码器预测点不能冒充抓取坐标。

**结果。** 这项要求成为车臂交接契约，减少重复采集计算，同时保留观测时间、单位、坐标系和补偿状态。图像复用本身不等于实物抓取成功。

依据：[共用结果与相机](../guides/vision.md)、[共用定位与交接](../guides/robot-task.md)、[共享接口提交 d96e439](https://github.com/WHU-SAS/aic-robot/commit/d96e439)。

## 先算清持续观察占用了多少精测时间

**问题。** 动态任务希望精测期间继续粗观察，但取图、粗检测、通信和调度会占用同一块 K230 的时间；增加观察也可能拖慢停车。

**我的干预。** 我先要求全程观察，随后连续追问：精测穿插粗测比只做精测多花多久？能否控制在 10%以内？如果明显拖慢，就应暂时取消穿插。静态任务的快速流畅优先，动态异常允许少许延迟。

**AI 随后的修改。** 调度改为精测优先，只有累计计算时间足以支付额外观察时才插入轻量粗测，不再机械地按固定高频率抢占精测。结果返回后优先补偿行程、下发距离命令，再恢复通常观察。

**结果。** 相互冲突的目标被转成可记录的预算和明确优先级。10%是软预算约束，单个原生调用不能随时抢占，不能将它宣传为端到端耗时的严格保证。

依据：[一台相机与分步调度](../guides/full-process-tracking.md)、[预算调度提交 d0703cb](https://github.com/WHU-SAS/aic-robot/commit/d0703cbe711bc70b7f5a8b419d6a18cc8dc2ff4e)。

## 旧图调通之后仍要防止过拟合和统计失真

**问题。** 反复看同一批失败照片并修改规则，可能让旧图表现变好，却不能证明新位置、新光照下同样有效。纯求解耗时、图像定位成功和实际夹取成功也容易被混为一谈。

**我的干预。** 我主动提出逐图优化是否会过拟合，要求正常照片能识别，并明确 98%不仅指图片定位，也包括实际夹取。精定位时间要求从拍照到可用结果，而不是只计算最后一个成功分支。

**AI 随后的修改。** 看过并用于改算法的图归入开发与回归集；独立验收先冻结代码、参数和规则，再采新图。验收图一旦用于修改，就不再是该版的独立验收样本。真实闭爪单独记一次尝试，空夹、掉落或恢复松开计失败，重试成功不抹掉前一次失败。

**结果。** 项目建立了较清晰的样本与指标口径。完整 1.5 秒定位时限、实际夹取至少 98%仍待独立验收，不能从旧图回放通过率或某几轮成功推断已经达标。

依据：[精定位算法的耗时与验收规则](../guides/vision.md)、[开发集与独立验收提交 c413360](https://github.com/WHU-SAS/aic-robot/commit/c41336006abbab5996d8a9e1f906f66cccc7d225)。
