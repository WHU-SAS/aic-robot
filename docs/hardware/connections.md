## 现有 PC 抓取

PC 分别通过 USB 连接 K230 OTG 和 URT-2；K230 提取视觉特征，PC 控制舵机。操作见 [Linux 指南](../guides/linux-arm.md)。下列 UART 直连是另一测试接法。

## K230 UART1 直连舵机

| K230 V3.0 | JP1 物理脚号 | URT-2 排针 |
| --- | --- | --- |
| IO_3 / UART1 TX | 18 | TX |
| IO_4 / UART1 RX | 13 | RX |
| GND | 按丝印 | GND |
| 5V | 按丝印 | 5V 逻辑供电 |

URT-2 的官方 MCU 接法为 **TX—TX、RX—RX**。电平开关置 **3V3**，拔除 URT-2 USB，舵机独立供电并共地、接 TTL-Bus。GPIO 编号不是物理脚号；测试前拆除 GPIO3/4 回环线。舵机 1 Mbps，回环测试 115200/8N1。K230直发准备位命令及操作见 [准备位脚本](../guides/arm/准备位脚本.md#通过k230发送)。

## K230 UART2 ↔ MSPM0 UART1

两板各自供电，只接以下三线，115200/8N1、无流控，不互连 5V/3V3 输出。

| K230 V3.0 | JP1 物理脚号 | MSPM0 |
| --- | --- | --- |
| IO_5 / UART2 TX | 17 | A09 / PA09 / UART1 RX |
| IO_6 / UART2 RX | 20 | A08 / PA08 / UART1 TX |
| GND | 按丝印 | GND |

IO_5 与 IO_3 同排，IO_6 与 IO_26 同排。MSPM0 UART0 的 PA10 TX / PA11 RX 另用于 115200/8N1 日志。

## K230补光灯

灯模块额定供电3～5V，DO高电平亮、低电平灭；DO接板上丝印`IO_26`，GND与K230共地，VCC按模块额定供电。IO26不是排针第26脚，不改现有IO3/4机械臂和IO5/6底盘通信线。

完整程序持有IO26输出对象：启动和语音待机时灭；“思达思达”回应后亮，空夹恢复／重试期间保持，抬升后满足现有夹取成功判据即灭；退出任务返回待机也灭。停止调试脚本后GPIO可能释放，不能用一次写0代替常驻灯控；这不是独立视觉持物验证。

## MSPM0 SWD

| fireDAP | 天猛星 | 已确认线色 |
| --- | --- | --- |
| VREF | 3V3 | 黑 |
| TCK / SWCLK | CLK / PA20 | 紫 |
| TMS / SWDIO | DIO / PA19 | 白 |
| GND | GND | 灰 |

主控由自身 Type-C 供电；VREF 是电压参考，不是供电输出。RST 可接已确认的 NRST，用于硬件复位或 Connect under Reset。下载设置见 [板端联调](../guides/k230-and-mspm0.md)。

新到的ARM V9调试器USB自报`J-Link V9.3 Plus`。2026-10-29已恢复USB权限并读到自身参考电压约3.32V，但100/50kHz的SWD尝试尚未读到目标调试端口，原生Commander也未连通。用户确认接线及主控供电；通过K230查询主控状态20/20成功，v1程序运行、输出为零，待检查复位期间的调试连接。其外壳标签将2脚标为3.3V输出VOUT，并称VTref与VOUT出厂默认内部短接；上述fireDAP的VREF接法不能直接套用。按该标签采用下列候选三线接法，不能把它视作所有J-Link通用接法：

| 新调试器20针接口 | 天猛星 |
| --- | --- |
| 7 / TMS / SWDIO | DIO / PA19 |
| 9 / TCK / SWCLK | CLK / PA20 |
| 4 / GND | GND |

1脚VTref、2脚VOUT、19脚5V均悬空，主控由自身Type-C独立供电。接线前拔除两者USB，按实物针号确认排线方向；旧线色不适用。内部参考电压不能证明主控已上电。若未读到合适的参考电压，停止连接排查，不直接补接VTref或开启输出。用户已确认接线，但该三线方案尚未连通目标，复位保持及兼容版本也未连通；未通过SWD下载固件，连接失败时拒绝了工具的整片擦除选项。此后通过主控Type-C的USB/BSL完成v2下载、CRC核验及UART2零输出确认；独立轮、定距/定角和连续视觉行驶的当前实测范围见[小车指南](../guides/car-approach.md)，这些结果不证明SWD可用。

## 电机与供电

2026-10-20只读采样确认：用户只手转左轮时A路计数大幅变化，B路基本稳定，因此 **A=左轮、B=右轮**。车头按用户确认的此前电机测试前进方向；该方向下原始编码计数A增加、B减少。当前驱动方向设置两路均为 `MOTOR_*_REVERSE=0`；此处只记录对应关系，未改动驱动方向或计数符号。

电机控制引脚及验收见 [底盘例程](../../device/mspm0/motor_encoder/README.md#接线)。驱动板手册标称输入 4.5～15 V，单路持续 ≤1.2 A、峰值 ≤3.2 A（不可持续）。主控由 USB 供电时，不再接驱动板的 5V/3V3 输出，只共地；电池不得直接接主控 Type-C、5V 或 3V3。

2026-10-20机械臂准备位下约1秒地面前进/停车通过，用户反馈无异常，六轴停车后仍开扭矩；持续带载、供电压降和极端负载尚未验收。此前的 11.1 V / 5000 mAh / 10C 是方案草案，不是上表现有电池参数。行驶姿态见 [准备位](../guides/arm/准备位脚本.md)。
